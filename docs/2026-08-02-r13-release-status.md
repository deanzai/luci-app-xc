# XC r13 发布与后续状态

更新时间：2026-08-02

## 已完成

- `636f229` 已推送到 `origin/main`，版本提升为 `0.1.0-r13`。
- 生成器新增按域名选择的 DNS 服务器，并将可路由 DNS 请求标记为当前选中节点。
- DNS 路由使用兼容 21.02/23.05/24.10 核心的顶层 `dns.tag=dns-in`；不依赖 25.4 以后才有的单个 NameServer `tag` 字段。
- `geosite.dat`、`geoip.dat` 资源检查和 `XRAY_LOCATION_ASSET` 兼容逻辑已纳入运行时与服务入口。
- 主机验证通过：Lua 368 项、LuCI DOM、翻译、IPK 结构、工作流和 21.02/23.05/24.10 矩阵检查全部通过。
- README 与 README_EN 的源码包、三平台主包/中文包和安装示例已统一为 `0.1.0-r13`。
- 21.02、23.05、24.10 目标设备的安装、配置备份、Xray `run -test`、服务状态和 LuCI 页面已完成验证；设备配置未被安装包覆盖。

## 发布资产

CI 会从 `main` 构建三套平台资产，并将主包、中文包和各平台 `SHA256SUMS` 统一命名为带平台后缀的 `0.1.0-r13` 文件。发布前必须确认：

1. 三个构建任务和主机测试均成功；
2. 每个 IPK 的 control 版本为 `0.1.0-r13`；
3. SHA256 清单远程下载后校验通过；
4. Release 只保留明确的 21.02、23.05、24.10 资产，不上传无平台后缀的同名文件。
